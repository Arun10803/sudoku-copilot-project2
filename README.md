# Sudoku (Python + Flask)

A Flask web application implementing a Sudoku puzzle generator with MRV backtracking uniqueness validation, conflict checking, light/dark themes, a Top 10 leaderboard, and `pytest` unit tests.

## Setup & Run

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
pytest
python app.py
